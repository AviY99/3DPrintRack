# R1-HOLE

Functional final version of V17T.3-Lite.

R1 uses **three Ø8.2 mm through-holes** at the triangle corners. The holes reduce corner material and can also serve as optional wall-mounting points.

## Primary files

- `STL/` — print-ready final STL.
- `STEP-Onshape/` — STEP solid for import into Onshape.
- `TEST-COUPON/` — one AF33 corner cell plus the complementary side-mate used to verify geometry and connector fit.
- `drawings/` — section and connector-fix images.
- `validation/` — machine-readable CAD validation.

See `SPECIFICATIONS.md` and `../docs/CONNECTOR_SPEC.md`.
