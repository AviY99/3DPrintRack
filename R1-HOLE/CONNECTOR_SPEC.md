# Connector Specification

Canonical connector specification: [../docs/CONNECTOR_SPEC.md](../docs/CONNECTOR_SPEC.md)

R1-HOLE uses the locked V16.8 profile without dimensional changes:

- Male: **5.2 / 8.2 mm**, depth **2.5 mm**
- Female: **5.7 / 8.7 mm**, depth **2.7 mm**
- Side clearance: **0.25 mm per side**
- Depth clearance: **0.20 mm**
