# Connector Specification

Canonical connector specification: [../CONNECTOR_SPEC.md](../CONNECTOR_SPEC.md)

This variant uses the locked V16.8 re-entrant profile without dimensional changes:

- Male neck/head: **5.20 / 8.20 mm**
- Male depth: **2.50 mm**
- Female mouth/inner width: **5.70 / 8.70 mm**
- Female depth: **2.70 mm**
- Side clearance: **0.25 mm per side**
- Total lateral difference: **0.50 mm**
- Depth clearance: **0.20 mm**
