# R2-CHEVRON

Design-oriented final variant of V17T.3-Lite.

R2 preserves the corrected R1 outer and connector geometry, but replaces the three Ø8.2 mm corner holes with symmetric through-chevron openings.

## Primary files

- `STL/` — print-ready final STL.
- `STEP-Onshape/` — STEP solid for import into Onshape.
- `TEST-COUPON/` — one AF33 corner cell with chevron plus the complementary side-mate.
- `drawings/` — section image.
- `validation/` — machine-readable CAD validation.

See `SPECIFICATIONS.md` and `../docs/CONNECTOR_SPEC.md`.
