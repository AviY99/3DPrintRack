# Connector Specification — V16.8

This is the canonical connector specification for **R1-HOLE**, **R2-CHEVRON**, and their test coupons.

The connector was physically validated by printing a test coupon. Its geometry is therefore **locked** and must not be changed without an explicit new revision and validation.

## Male

| Parameter | Value |
|---|---:|
| Neck | **5.20 mm** |
| Head | **8.20 mm** |
| Depth | **2.50 mm** |

## Female

| Parameter | Value |
|---|---:|
| Mouth | **5.70 mm** |
| Inner width | **8.70 mm** |
| Depth | **2.70 mm** |

## Clearances

- Side clearance: **0.25 mm per side**
- Total lateral difference: **0.50 mm**
- Depth clearance: **0.20 mm**

## Definition

**V16.8 re-entrant locking connector**

## Z length

- Full R1/R2 parts: **65 mm**
- Test coupons: **32.5 mm**
- Connector cross-section: **identical**

## Change rule

Do not modify this connector geometry as part of packaging, repository cleanup, STL upload, STEP upload, or documentation work. Any geometric change requires an explicit request and a new validation cycle.
